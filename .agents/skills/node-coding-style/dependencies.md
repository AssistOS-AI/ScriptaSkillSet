# Dependencies

## Scope

This record covers the complete `node-coding-style` skill folder. The skill consists of instructions, catalog metadata, a design summary, and a Markdown template. Reading or copying it requires no Node.js or Python runtime, CLI tool, package installation, network request, or sibling skill.

## Runtime prerequisites

None for the skill itself. Code generated under this style targets Node.js; each consuming project records the Node.js version required by the APIs it actually uses in its own `dependencies.md`.

## External dependencies

None. No third-party code is bundled, no license exception has been accepted, and no global installation is required. The public license URLs in `SKILL.md` are reference material, not runtime dependencies.

## Maintenance

Keep this inventory with the copied skill. Record any future accepted dependency here, including its justification, alternatives, source and update URLs, pinned revision, exact license and retained notices, location, transitive requirements, startup checks, authorization, and removal opportunity. Use `assets/dependencies.md` for dependency records in generated projects or skills.
